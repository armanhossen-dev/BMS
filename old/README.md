# Bank Management System

A web-based banking application built using PHP, MySQL, HTML, CSS, and JavaScript. It manages customers, accounts, transactions, loans, and daily banking operations through a modern, premium dashboard interface designed for efficiency and usability.

---

## Tech Stack

PHP · MySQL · HTML5 · CSS3 · JavaScript

---

## Getting Started

**Requirements:** XAMPP installed on your machine.

**1. Start XAMPP**

Open the XAMPP Control Panel and start both **Apache** and **MySQL**.

**2. Set up the database**

- Go to `http://localhost/phpmyadmin`
- Create a new database named `bank_management`
- Import the file at `sql/bank_db.sql`

**3. Move the project**

Copy the `bms` folder into:
```
C:/xampp/htdocs/
```

**4. Open in browser**
```
http://localhost/bms/landing.php
```
