SETUP REMINDERS
---------------
- DB name: bank_management
- DB user: root
- DB password: (empty by default on XAMPP)
- DB host: localhost
- Config file: config/db.php  <-- change credentials here if needed
- Project must be inside C:/xampp/htdocs/bms/ or paths will break
- Always start Apache + MySQL before opening the site
- PHP version tested on: 8.x (XAMPP default)


KNOWN BUGS
----------
- Session doesn't always clear properly on logout in some browsers, 
  clear cookies manually if login gets stuck
- Transfer page doesn't validate if sender and receiver account are 
  the same — need to add that check
- Loan status doesn't auto-update, has to be changed manually by staff
- Report page loads slow with large transaction data, no pagination yet
