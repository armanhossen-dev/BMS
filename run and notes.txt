1. QUICK START: HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------

METHOD A: Via XAMPP (Apache + MySQL)
  1. Open XAMPP Control Panel.
  2. Start "Apache Web Server".
  3. Start "MySQL Database" (If it fails on Mac, see Section 2 below).
  4. Open your browser and navigate to:
     http://localhost/BMS/

METHOD B: Via Built-in PHP Server (Fastest CLI Method)
  1. Open Terminal and navigate to the project directory:
     cd /Applications/XAMPP/xamppfiles/htdocs/BMS
  2. Start the local PHP development server:
     php -S localhost:8000
  3. Open your browser and visit:
     http://localhost:8000/


--------------------------------------------------------------------------------
2. MAC SPECIFIC ISSUE: XAMPP MYSQL FAILS TO START (PORT 3306 CONFLICT)
--------------------------------------------------------------------------------

Symptom:
  In XAMPP Manage Servers, clicking "Start" on MySQL Database attempts to run,
  turns orange, and immediately stops back to red.

Cause:
  Homebrew MySQL (`/opt/homebrew/opt/mysql/bin/mysqld`) is already running in
  the background and occupies port 3306. Two MySQL servers cannot bind to 3306
  at the same time.

Solution 1 (Recommended if you want XAMPP's MySQL to start):
  1. Stop Homebrew's MySQL service via Terminal:
     brew services stop mysql

  2. Verify port 3306 is released:
     lsof -i :3306

  3. Return to XAMPP Control Panel and click "Start" on MySQL Database.
     It will now start and turn green.

Solution 2 (Use Homebrew's MySQL with XAMPP Apache):
  - Homebrew's MySQL is already running with `asha_bank` database loaded!
  - You do NOT need XAMPP's MySQL if Homebrew MySQL is running.
  - The PHP app in `config/db.php` connects to `127.0.0.1:3306` seamlessly.
  - Just leave Apache running in XAMPP and use your site as normal.

5. DATABASE CONFIGURATION & IMPORT
--------------------------------------------------------------------------------

Configuration File:
  /Applications/XAMPP/xamppfiles/htdocs/BMS/config/db.php

Default Settings:
  DB_HOST = '127.0.0.1'
  DB_PORT = '3306'
  DB_NAME = 'asha_bank'
  DB_USER = 'root'
  DB_PASS = ''

How to Import Schema Manually (CLI):
  mysql -u root < /Applications/XAMPP/xamppfiles/htdocs/BMS/database.sql

  Or if using XAMPP's bundled binary:
  /Applications/XAMPP/xamppfiles/bin/mysql -u root < /Applications/XAMPP/xamppfiles/htdocs/BMS/database.sql

Why CLI or phpMyAdmin Import is Preferred:
  The database schema contains `DELIMITER $$` blocks for stored procedures,
  triggers, and functions. Native CLI or phpMyAdmin import handles this cleanly.

8. USEFUL MAC TERMINAL COMMANDS
--------------------------------------------------------------------------------

- Stop Homebrew MySQL:
  brew services stop mysql

- Start Homebrew MySQL:
  brew services start mysql

- Check what is listening on port 3306:
  lsof -i :3306

- Test database connection via PHP:
  php -r "require 'config/db.php'; echo 'DB Connected! Customer Count: ' . \$pdo->query('SELECT COUNT(*) FROM CUSTOMER')->fetchColumn() . PHP_EOL;"

- Check XAMPP Apache status:
  ps aux | grep httpd | grep -v grep
